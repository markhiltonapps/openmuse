Plan: docs/RECEIPT-BOX-PLAN.md (API table, privacy, phases). Mockups: ten boards, two review rounds (scratchpad, not in the repo).

Server (apps/server/src):
  receipt-reader.ts   prompt, strict zod shape, tolerant parser, reconcile() (settles a smudged total from the receipt's own sums,
                      tax-included totals count), date/plausibility checks, readReceipt() with one retry.
  receipt-box.ts      store kind "receipt-box" (NOT "receipts": that word is the "What I used" privacy receipts), snap / snapFile /
                      update / file / unfile / setReturn / remove / summary / list, duplicates flagged not dropped, auto-file only for
                      sure reads, streak of ten unchanged checks, reminders through ReminderService (3 days before at 9, else that
                      morning; `reminderAt` is the real time), safety cap 30 reads an hour / 120 a day (not a plan limit).
  receipt-tools.ts    ONE chat tool receipt_box (read, fix, file, unfile, to_check, find), "shown" claimed only in chat, never on a call.
  app.ts routes       /api/receipt-box (summary), /snap (multipart photo), /auto-file, /:id (GET, POST), /:id/file, /unfile, /return, /delete.
  vision.ts           lookAtImage takes maxTokens (receipts use 4000); usage kind "receipts"; RECEIPT_MODEL overrides the model.
App (apps/mobile/src/receipt-box-*.ts(x), 10 files + test): box sheet (list, two panes on desktop), snap flow (downscale to 1600px,
