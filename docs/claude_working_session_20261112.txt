=== PWR button: second path through the power chip (uncompiled) ===
Owner's Serial Monitor showed nothing when pressing PWR (no "[pwr] GPIO10" lines), so GPIO10 may not carry this unit's button (it was not
established whether the monitor showed the boot lines; the boot banner "Neddy device 0.1.0" and a new "[dbg] alive, GPIO10=N" every 5 s under
DEBUG_SERIAL tell). Added pmuKeyShort(): enables the AXP2101 key interrupts (0x41 |= 0x0F) and reads/clears its second status byte 0x49 every
40 ms (bit 3 short press, 2 long, 1 released, 0 pressed; register layout from the AXP2101 datasheet / Zephyr's driver); a short press does the
same as a GPIO10 press (opens the menu, or leaves the recorder screen). Prints "[pwr] power chip key status 0xNN" on any change.
Needs a flash to test; if "[dbg] alive" never prints the debug output itself is not reaching the Serial Monitor (check DEBUG_SERIAL in settings.h,
USB CDC On Boot enabled, 115200 baud, reset the watch after opening the monitor).

=== Battery not detected (owner plugged one in) ===
Owner's message was cut off ("Is there a way for you to…"). The watch reads the AXP2101: present if status0 bit 3 is set or the battery voltage register (0x34/0x35) is 2.8-4.6 V;
percent from 0xA4, else estimated from the voltage; charging from status1. Added a serial line under DEBUG_SERIAL every 5 s (first looks) then 30 s: "[batt] status0=.. status1=..
battery_mV=.. present=.. percent=.. charging=.. usb=..". On screen the idle/normal screen's bottom line shows the raw bytes when no battery is read. Safety note given: check the
battery's polarity against the board's +/- marks before plugging; a reversed battery can destroy the board.
